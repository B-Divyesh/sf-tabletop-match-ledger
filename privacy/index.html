Privacy, by keeping score locally.

Players, scores, notes, and match history stay in this browser’s IndexedDB. We do not run accounts, analytics, advertising, or a cloud score database.

Data on your device

The app stores your current match so it survives refreshes and offline play. The sample demo uses a separate storage key. You can export JSON or CSV and clear the current match. Clearing browser site data also removes it.

Purchase and license data

Sociobot/Dodo handles checkout as merchant of record for the optional Table Keeper purchase. The app stores your license token and last result in local storage. It sends the token to api.sociobot.in at most once daily. Payment details never reach this app.

Sharing and imports

Pairing sends match data directly to the device whose code you accept. No signaling server receives the pairing codes. Exports, imports, clipboard copies, and system sharing run only when you request them.
